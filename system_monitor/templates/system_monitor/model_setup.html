Before you start

  • Verify that the model's official documentation and license allow local, non-commercial or commercial use as required.
  • Check Windows support, VRAM requirements, dependencies, and model size before downloading.
  • Choose a model that fits the hardware detected on the diagnostics page.
  • Never download large model weights automatically without reviewing the download size and storage requirements.

Local generation does not require a paid API key, but hardware, electricity, storage, and generation time still have real costs.

Option A — ComfyUI (recommended for flexibility)

Run a local ComfyUI instance and point CineForge AI at it via the COMFYUI_BASE_URL setting.

  • Install ComfyUI for your platform.
  • Install a maintained video-generation workflow and model inside ComfyUI.
  • Confirm the workflow works end-to-end in ComfyUI before using it here.
  • Export it with Save (API Format) and replace the prompt, seed, size, FPS, and duration values with the documented tokens.
  • Set COMFYUI_BASE_URL and COMFYUI_WORKFLOW_PATH in your environment.

Option B — Direct model adapter

For models that expose a direct runtime, a dedicated adapter can be added later. This project ships a CPU-only demo adapter (generator/adapters_demo.py) for pipeline validation without a GPU.

  • Install the model backend and verify it runs locally.
  • Add or configure the corresponding adapter in generator/adapters.py.
  • Validate settings against the installed model before starting a job.

If no suitable GPU is available, the application will explain the limitations on the diagnostics page and offer a CPU demo path.

Important:
  • Character consistency and scene continuity in multi-scene films are model-dependent, not guaranteed by this application.
  • This app will not promise successful generation before verifying that a compatible model and workflow are installed.
